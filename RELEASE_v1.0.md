# Evidence Archive v1.0

Release checkpoint for the public Evidence Archive at `https://axamir.github.io/echoes-consented-record/`.

## Included

- Source-first reading room with a published archival boundary.
- Seven-stage Echo sequence, including an inline opening primary record.
- Searchable source ledger generated from 91 archived PDFs.
- Five published Case IDs represented in the ledger metadata.
- In-page PDF reader with a direct GitHub source path for every record.
- Verification guide, SHA256 and timestamping references as published in the source repository.
- Canonical URL, Open Graph/Twitter metadata, favicon, robots policy, and sitemap.

## Validation

- Static build completes with 91 source PDFs.
- JavaScript syntax checks pass.
- GitHub Pages deployment completes successfully.
- Public checks confirm the source ledger and representative primary PDFs are reachable.

This release is a navigation and reading layer for published records. It does not adjudicate or infer the intent, meaning, or status of the underlying correspondence.
